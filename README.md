## 📋 Разделы сайта

- **Hero** — главный экран с параллакс-эффектом и кнопкой перехода к меню
- **О нас** — история и факты о кофейне
- **Меню** — карточки напитков и десертов с ценами
- **Атмосфера** — фотогалерея заведения
- **Отзывы** — слайдер с отзывами клиентов
- **Контакты** — форма обратной связи, адрес и режим работы

---

## ⚡️ Функциональность

### 🎨 Дизайн
- Тёплая кофейная палитра — бежевый, коричневый, карамель
- Шрифты: `Playfair Display` + `Inter`
- Полная адаптивность — mobile / tablet / desktop

### ✨ Фишки
- 🖱 Кастомный курсор с плавным следованием
- 📜 Scroll-анимации через `Intersection Observer`
- 🌊 Ripple-эффект на кнопках
- 🔢 Анимация числовых счётчиков
- 📱 Свайп в слайдере (touch + mouse drag)
- 🛎 Toast-уведомления при добавлении в заказ
- ⬆️ Кнопка scroll-to-top
- ⌨️ Keyboard-навигация (стрелки, Escape)
- 🎯 Автоподсветка активных ссылок при скролле
- 🖼 Защита изображений от скачивания
